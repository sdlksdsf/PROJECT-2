# Keyboard shortcuts

`Ctrl` on Windows/Linux, `⌘` on macOS. All bindings can be changed in **Settings → Shortcuts**.

## Tabs and windows

| Shortcut | Action |
| :--- | :--- |
| `Ctrl/⌘ T` | New tab |
| `Ctrl/⌘ W` | Close tab |
| `Ctrl/⌘ Shift T` | Reopen the last closed tab |
| `Ctrl/⌘ Tab` / `Ctrl/⌘ Shift Tab` | Next / previous tab |
| `Ctrl/⌘ 1…9` | Jump to tab by position |
| `Ctrl/⌘ N` | New window |
| `Ctrl/⌘ Shift N` | New private window |
| `Ctrl/⌘ Shift W` | Close window |
| `Ctrl/⌘ Shift M` | Mute / unmute all tabs |
| `F11` | Full screen |

## Navigation

| Shortcut | Action |
| :--- | :--- |
| `Ctrl/⌘ L` or `F6` | Focus address bar |
| `Ctrl/⌘ K` | Command palette |
| `Alt ←` / `Alt →` | Back / forward |
| `F5`, `Ctrl/⌘ R` | Reload |
| `Ctrl/⌘ Shift R` | Reload ignoring cache |
| `Esc` | Stop loading |
| `Ctrl/⌘ +` / `−` / `0` | Zoom in / out / reset |
| `Home` / `End` | Top / bottom of page |
| `Space` / `Shift Space` | Page down / up |

## Split view and panes

| Shortcut | Action |
| :--- | :--- |
| `Ctrl/⌘ Shift \` | Split with the next tab (or unsplit) |
| `Ctrl/⌘ Shift ←/→` | Move focus between panes |
| `Ctrl/⌘ Shift X` | Swap panes |
| `Ctrl/⌘ Shift P` | Pop the focused pane into its own window |

## Privacy and data

| Shortcut | Action |
| :--- | :--- |
| `Ctrl/⌘ Shift Delete` | Erase browsing data dialog |
| `Ctrl/⌘ Shift I` | Site information / shield panel |
| `Ctrl/⌘ Shift J` | Blocked-request log for the current site |
| `Ctrl/⌘ Shift H` | History |
| `Ctrl/⌘ Shift O` | Bookmark manager |
| `Ctrl/⌘ D` | Bookmark this page |
| `Ctrl/⌘ Shift B` | Toggle bookmarks bar |

## Tools

| Shortcut | Action |
| :--- | :--- |
| `Ctrl/⌘ Shift S` | Screenshot (visible area, full page with `Shift`) |
| `Ctrl/⌘ Shift A` | AI panel |
| `Ctrl/⌘ Shift F` | Focus mode (timer + blocklist) |
| `Ctrl/⌘ Shift G` | Toggle Game mode (aggressive freezing) |
| `Ctrl/⌘ Shift L` | Toggle force-dark on this site |
| `Ctrl/⌘ Shift U` | Toggle typing sounds |
| `Ctrl/⌘ Shift I` | Developer tools for the focused page |
| `Ctrl/⌘ Shift Esc` | Task view: memory and CPU per tab |
| `Ctrl/⌘ ,` | Settings |
| `Ctrl/⌘ Shift Y` | Downloads |
| `Ctrl/⌘ Q` | Quit Kimmino |

## Screenshots

| Action | Result |
| :--- | :--- |
| `Ctrl/⌘ Shift S` | Visible area → `Pictures/Kimmino/kimmino-2026-11-19-2114.png` |
| `Ctrl/⌘ Shift S` then `F` | Full page, including scrollable area |
| `Ctrl/⌘ Shift S` then `C` | Copy to clipboard, do not save |

Format (PNG/JPEG), quality and save location are configurable in **Settings → Downloads → Screenshots**.

## Address bar and search

| Key | Action |
| :--- | :--- |
| `Alt Enter` | Open the typed address in a new tab |
| `Ctrl/⌘ Enter` | Add `.com` and open |
| `Shift Delete` | Remove the highlighted suggestion from history |
| `Tab` | Cycle suggestion categories (history → bookmarks → open tabs → search) |
| `Ctrl/⌘ K` inside omnibox | Same, with the palette |

## Developer

| Shortcut | Action |
| :--- | :--- |
| `Ctrl/⌘ Shift I` | DevTools |
| `Ctrl/⌘ Shift C` | Inspect element |
| `Ctrl/⌘ Shift O` | DevTools console |
| `Ctrl/⌘ Shift M` (DevTools focused) | Toggle device emulation |
| `Ctrl/⌘ U` | View page source in a private tab |
